# AI task routing for this Godot project

Before starting a user-requested task in this repository, read and follow `.agents/skills/godot-task-router/SKILL.md`. Classify the task and state the routing decision before making project changes. If the current agent is not the owner, stop without editing files and return the handoff format from the skill. This rule does not block read-only inspection needed to classify the task.

Project-specific rules (Godot version, naming, architecture, tests) may be added below. If they conflict with the router, follow project-specific technical requirements while preserving the task ownership and handoff rules.
